# 🤖 AI-AUTOMATION

An automation project built using **Python**, **Twilio API**, and **GitHub Actions** to automatically send WhatsApp messages. This project demonstrates workflow automation, scheduled task execution, and cloud-based messaging using Twilio's WhatsApp API.

## 🚀 Features

- Automated WhatsApp message sending
- Integration with Twilio WhatsApp API
- GitHub Actions workflow automation
- Scheduled task execution using YAML workflows
- Secure handling of secrets and API credentials
- Lightweight and scalable setup

## 🛠️ Technologies Used

- Python
- Twilio API
- GitHub Actions
- YAML
- WhatsApp API
